# Audio

## Credits

Music is by **Abstraction** — <https://abstractionmusic.com/>. The credit is
shown in-game on the About page (`scenes/about.gd`); keep it there, and check
the licence terms before shipping or swapping the tracks.

Sound effects in `sfx/` are still **placeholders** generated by
`tools/gen_audio.py`. They exist so the game has working audio without
shipping licensed assets — replace them freely.

## Replacing a sound

Drop your file in with the **same base name**. The format does not need to
match: `Audio` resolves each name against `.wav`, `.ogg` and `.mp3` in that
order, so `place.ogg` transparently replaces `place.wav`. Delete the file you
are replacing, or the earlier extension keeps winning.

Godot must import a new file before it can load it:

```bash
/Applications/Godot.app/Contents/MacOS/Godot --headless --import --path .
```

A missing file is not an error — it logs a warning and plays nothing, so the
game keeps running while assets are being swapped.

## What plays when

| File | Trigger |
|---|---|
| `music/beach_house`, `high_end_party`, `light_music` | Menu bed — the front of the game, in that fixed order |
| `music/*.ogg` (the rest) | In-game bed, shuffled |
| `music/game_over.ogg` | Plays once when a run ends (lost, or nothing in the tray fits) |
| `sfx/tap.wav` | Any menu button |
| `sfx/deal.wav` | A fresh tray is dealt |
| `sfx/place.wav` | A piece is placed |
| `sfx/clear.wav` | A row or column clears (combo 1) |
| `sfx/combo.wav` | A clear at combo 2+; pitch rises with the streak |
| `sfx/bomb.wav` | Bomb detonates |
| `sfx/laser.wav` | Laser fires |
| `sfx/collapse.wav` | Board collapses |
| `sfx/fit.wav` | Fit piece lands |
| `sfx/game_over.wav` | Run ends |

## Music selection

File names are `snake_case`; the game addresses tracks by base name.

There are **two beds**, chosen by screen in `App._playlist_for()`:

| List | Tracks | Order | Repeats |
|---|---|---|---|
| `MENU` | `MENU_TRACKS` — beach_house, high_end_party, light_music | authored | 4x each |
| `GAME` | everything else in the folder | shuffled | 5x each |

A track repeats `MENU_REPEATS` / `GAME_REPEATS` times before the playlist
advances. Switching screens between two menu screens does not restart the
track; entering or leaving the play screen switches lists and starts the new
one cleanly.

Other tracks are **scanned from `assets/audio/music/` at runtime**, so dropping a file
in is enough — no code change. Selection rules, all in `scripts/audio.gd`:

- `MUSIC_EXCLUDE` — never shuffled. `game_over` (reserved as the lose stinger)
  and `theme` (the old generated placeholder).
- `MIN_TRACK_SECONDS` (20s) — anything shorter is skipped. The asset pack also
  ships short stingers and beat loops (2–9s: `level_up*`, `victory`,
  `effects_a`–`effects_d`, `beats_*`, `temple_miniclips`); in a playlist that advances
  when a track finishes, those would change the music every few seconds. Set
  it to `0.0` to shuffle everything regardless of length — or move those files
  to `assets/audio/sfx/` where they are more useful.

The shuffle is a bag: every eligible track plays once before any repeats, and
a refill will not replay the track that just ended. Playlist tracks do **not**
loop — looping would stop `finished` firing, so the playlist would never
advance.

## Guidance

- **Effects**: keep them under ~0.5s and leave headroom — up to 8 can overlap
  (`Audio.VOICES`), and a cascading clear fires several in one frame.
- **Music**: must loop cleanly. For a **WAV**, set `edit/loop_mode` to
  `Forward` in Godot's Import dock (or in the `.wav.import` file) and
  reimport — that bakes correct loop points. `Audio.play_music()` also forces
  looping at runtime as a fallback, but prefer the import setting.

  > Enabling `loop_mode` **without** a loop region is the trap here: a WAV
  > whose `loop_end` is 0 loops over a zero-length window, so the player
  > reports `playing == true`, the playback position never advances past one
  > sample, and nothing is audible. If music seems dead, check
  > `loop_end`, not `playing`.
- **Levels**: effects sit at −4 dB and music at −8 dB (`Audio.SFX_HEADROOM_DB`
  / `MUSIC_HEADROOM_DB`) before the player's volume setting is applied.
- Prefer `.ogg` for music: the placeholder WAV is 795 KB, where an equivalent
  Ogg is nearer 100 KB.

## Regenerating

`python3 tools/gen_audio.py` rewrites every file here. Note that Godot's Movie
Maker mode writes a `.wav` next to its frame output — keep capture output
outside the project so it cannot land on top of these.

## Settings

Music on/off, sound on/off and music volume live on the settings screen and
persist to `user://settings.cfg` under `[audio]`.
